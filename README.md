# korail-watch — 코레일 공석 감시 → 텔레그램 알림

지정한 날짜·시간·인원 조건으로 **코레일(korail.com) 열차를 주기적으로 조회**하고,
매진이던 좌석에 **공석이 나면 텔레그램으로 즉시 알려주는** 커맨드라인 도구.

## 왜 브라우저가 필요한가

코레일은 `dynaPath` 안티매크로로 보호됩니다. 순수 HTTP 요청(curl, 단순 fetch)은
`macro_err1` 로 차단됩니다. 그래서 이 도구는:

1. **자동화 플래그 없는 진짜 Chrome**을 원격 디버깅 포트로 실행하고
2. 조회를 1회 실행해 dynaPath **신뢰 상태를 "예열"**한 뒤
3. 그 브라우저 컨텍스트 안에서 조회 API를 주기적으로 호출합니다.

> Playwright/헤드리스가 직접 띄운 브라우저는 탐지되어 막힙니다. 반드시 이 방식이어야 통과합니다.

## 준비

```bash
npm install
npx playwright install chromium   # (이미 설치돼 있으면 생략)
```

`.env` 에 텔레그램 정보가 있어야 합니다:

```
TELEGRAM_BOT_TOKEN=123456:AA...
TELEGRAM_CHAT_IDS=556744257        # 쉼표로 여러 명 가능
```

## 사용법

```bash
# 12:00 ~ 16:00 사이 출발 열차만 감시
node watch.js --date 2026-07-17 --time 12:00 --time-to 16:00 --from 광명 --to 서대전 --adults 1 --infants 1 --interval 60
```

| 인자 | 설명 | 기본값 |
|------|------|--------|
| `--date` | 승차일 YYYY-MM-DD **(필수)** | |
| `--from` | 출발역 이름 **(필수)** | |
| `--to` | 도착역 이름 **(필수)** | |
| `--time` | 이 시각(HH:MM) 이후 출발 열차만 | `00:00` |
| `--time-to` | 이 시각(HH:MM) 이전 출발 열차만 (범위 상한) | 제한 없음 |
| `--adults` | 어른 수 | `1` |
| `--children` | 어린이 수 | `0` |
| `--infants` | 유아 수 | `0` |
| `--seniors` | 경로 수 | `0` |
| `--seat-class` | `gen`(일반실) / `any`(일반실+특실) / `spe`(특실만) / `standing`(입석·자유석) | `gen` |
| `--trains` | 특정 열차번호만 (예: `587,589`) | 전체 |
| `--interval` | 조회 주기(초) | `60` |
| `--once` | 1회만 조회 후 종료(테스트) | |
| `--port` | Chrome 원격 디버깅 포트 | `9222` |
| `--no-telegram` | 텔레그램 미전송(콘솔만) | |

멈추려면 `Ctrl+C`.

## 동작 방식 메모

- **Windows / macOS / Linux 모두 지원**합니다. OS별 Chrome 설치 경로를 자동 탐색합니다(못 찾으면 이미 실행 중인 크롬에 `--port`로 붙이면 됩니다).
- 처음 실행 시 전용 프로필(`./.chrome-profile`)로 Chrome 창이 하나 뜹니다. **창은 그대로 열어두세요**(닫으면 감시 중단). 최소화는 무방.
- 이미 `--port` 포트에 크롬이 떠 있으면 새로 띄우지 않고 붙습니다.
- 조회가 `macro_err`로 막히면 자동으로 재예열 후 재시도합니다.
- 일반실·특실은 시간표의 단순 예약가능 표시만 믿지 않고, 코레일 웹의 **좌석선택과 같은 조회**를 한 번 더 수행합니다. 지정 인원이 함께 선택할 수 있는 호차가 있을 때만 알림을 보냅니다.
- 옵션을 생략하면 일반실만 감시합니다. 특실도 함께 보려면 `--seat-class any`, 특실만 보려면 `--seat-class spe`를 사용하세요.
- 콘솔 상태는 `🟢` 좌석선택 가능, `🟡` 예약가능 표시는 있으나 선택 가능한 좌석조합 없음, `·` 매진, `?` 좌석검증 일시 실패를 뜻합니다.
- 같은 열차·좌석은 한 번만 알림하고, 다시 매진됐다가 재오픈되면 다시 알립니다.

- PC가 절전/최대절전에 들어가면 감시가 멈춥니다.
