# korail-watch — 코레일 공석 감시 → 좌석선택 예약 → 텔레그램 알림

지정한 날짜·시간·인원 조건으로 **코레일(korail.com) 열차를 주기적으로 조회**하고,
매진이던 좌석에 공석이 나면 **텔레그램으로 알려주거나, 원하는 좌석을 골라 예약한 뒤
텔레그램으로 알려주는** 커맨드라인 도구입니다. 결제는 자동으로 진행하지 않습니다.

## 왜 브라우저가 필요한가

코레일은 `dynaPath` 안티매크로로 보호됩니다. 순수 HTTP 요청(curl, 단순 fetch)은
`macro_err1` 로 차단됩니다. 그래서 이 도구는:

1. **자동화 플래그 없는 진짜 Chrome**을 원격 디버깅 포트로 실행하고
2. 조회를 1회 실행해 dynaPath **신뢰 상태를 "예열"**한 뒤
3. 그 브라우저 컨텍스트 안에서 조회 API를 주기적으로 호출합니다.

> Playwright/헤드리스가 직접 띄운 브라우저는 탐지되어 막힙니다. 반드시 이 방식이어야 통과합니다.

## 준비

```bash
npm install
npx playwright install chromium   # (이미 설치돼 있으면 생략)
```

`.env` 에 텔레그램 정보가 있어야 합니다:

```
TELEGRAM_BOT_TOKEN=123456:AA...
TELEGRAM_CHAT_IDS=556744257        # 쉼표로 여러 명 가능
```

자동 로그인을 사용하려면 아래 값을 추가하세요. `.env`는 Git에서 제외됩니다.

```
KORAIL_ID=1234567890
KORAIL_PW=...
```

`--reserve` 실행 시 기존 로그인 세션이 없으면 위 정보로 자동 로그인합니다.
기존 `KORAIL_MEMBER_ID`, `KORAIL_PASSWORD` 이름도 호환됩니다.

필요하면 수동 로그인도 사용할 수 있습니다.

```bash
node watch.js --login
```

전용 Chrome 창에서 직접 로그인하면 세션이 `./.chrome-profile`에 저장됩니다.

## 설정 화면으로 실행하기

Windows에서는 [`korail-ui.cmd`](./korail-ui.cmd)를 더블클릭하세요. 브라우저에 로컬
설정 화면이 열리며 날짜, 역, 시간대, 승객, 좌석 종류와 실행 방식을 선택할 수 있습니다.

1. 조건을 입력하면 아래에 기존 CLI 명령어가 실시간으로 표시됩니다.
2. **감시 시작**을 누르면 설정 화면을 연 터미널에서 `watch.js`가 실행됩니다.
3. 실행 후 웹 페이지는 닫아도 되며, 진행 상황은 터미널에서 확인합니다.

터미널에서 설정 화면을 열려면 다음 명령도 사용할 수 있습니다.

```bash
npm run ui
```

설정 화면은 외부에 공개되지 않고 현재 PC의 `127.0.0.1` 주소에서만 잠시 열립니다.
입력값은 기존 CLI 인자로 변환되므로 아래의 명령줄 사용법도 그대로 사용할 수 있습니다.

## 사용법

```bash
# 알림만 받기(기존 동작)
node watch.js --date 2026-07-17 --time 12:00 --time-to 16:00 --from 광명 --to 서대전 --adults 1 --infants 1 --interval 60

# 실제 예약 없이 선택될 좌석 확인
node watch.js --date 2026-07-17 --time 12:00 --time-to 16:00 --from 광명 --to 서대전 --adults 1 --infants 1 --trains 587 --dry-run-reserve --once --no-telegram

# 좌석선택 예약: 첫 예약 1건이 성공하면 텔레그램 알림 후 종료
node watch.js --date 2026-07-17 --time 12:00 --time-to 16:00 --from 광명 --to 서대전 --adults 1 --infants 1 --trains 587 --reserve --interval 60
```

| 인자 | 설명 | 기본값 |
|------|------|--------|
| `--date` | 승차일 YYYY-MM-DD **(필수)** | |
| `--from` | 출발역 이름 **(필수)** | |
| `--to` | 도착역 이름 **(필수)** | |
| `--time` | 이 시각(HH:MM) 이후 출발 열차만 | `00:00` |
| `--time-to` | 이 시각(HH:MM) 이전 출발 열차만 (범위 상한) | 제한 없음 |
| `--adults` | 어른 수 | `1` |
| `--children` | 어린이 수 | `0` |
| `--infants` | 유아 수 | `0` |
| `--seniors` | 경로 수 | `0` |
| `--seat-class` | `gen`(일반실) / `any`(일반실+특실) / `spe`(특실만) / `standing`(입석·자유석) | `gen` |
| `--trains` | 특정 열차번호만 (예: `587,589`) | 전체 |
| `--interval` | 조회 주기(초) | `60` |
| `--once` | 1회만 조회 후 종료(테스트) | |
| `--reserve` | 공석 발견 시 좌석을 선택해 예약. 첫 성공 후 종료 | 사용 안 함 |
| `--dry-run-reserve` | 예약하지 않고 선택할 좌석만 출력 | 사용 안 함 |
| `--login` | 전용 Chrome에서 수동 로그인만 진행 후 종료 | |
| `--login-timeout` | 수동 로그인 대기시간(초) | `300` |
| `--port` | Chrome 원격 디버깅 포트 | `9222` |
| `--no-telegram` | 텔레그램 미전송(콘솔만) | |

멈추려면 `Ctrl+C`.

## 동작 방식 메모

- **Windows / macOS / Linux 모두 지원**합니다. OS별 Chrome 설치 경로를 자동 탐색합니다(못 찾으면 이미 실행 중인 크롬에 `--port`로 붙이면 됩니다).
- 처음 실행 시 전용 프로필(`./.chrome-profile`)로 Chrome 창이 하나 뜹니다. **창은 그대로 열어두세요**(닫으면 감시 중단). 최소화는 무방.
- 이미 `--port` 포트에 크롬이 떠 있으면 새로 띄우지 않고 붙습니다.
- 조회가 `macro_err`로 막히면 자동으로 재예열 후 재시도합니다.
- 일반실·특실은 시간표의 단순 예약가능 표시만 믿지 않고, 코레일 웹의 **좌석선택과 같은 조회**를 한 번 더 수행합니다. 지정 인원이 함께 선택할 수 있는 호차가 있을 때만 알림을 보냅니다.
- 기본값은 기존과 동일한 **알림 전용 모드**입니다. 실제 예약은 `--reserve`를 명시했을 때만 수행합니다.
- 자동 예약은 시간표 순서상 가장 먼저 발견한 열차부터 시도하며, **예약 1건이 성공하면 즉시 감시를 종료**합니다. 결제는 절대 자동으로 진행하지 않습니다.
- 좌석 우선순위는 다음과 같습니다.
  1. 유아가 있으면 유아 수만큼 성인과 붙은 좌석 쌍을 반드시 확보
  2. 전체 인원의 붙은 좌석 쌍을 최대한 많이 확보
  3. 순방향 우선, 역방향 회피
  4. `4인동반석`으로 표시된 마주보기 좌석 회피
  5. 앞·뒤 끝 호차보다 중앙에 가까운 호차 우선
- 유아 좌석은 예약 요청의 승객 순서에서도 성인과 인접석으로 매핑되도록 정렬합니다.
- 현재 자동 예약은 **직통 열차의 일반실·특실 좌석**만 지원합니다. 환승 여정과 입석·자유석은 잘못된 일부 예약을 막기 위해 거부합니다.
- 예약 직전에 로그인 세션이 만료되면 `.env` 자격정보가 있을 때 한 번 다시 로그인합니다. 자격정보가 없으면 수동 로그인을 다시 해야 합니다.
- 예약 성공 알림에는 열차, 호차·좌석, 예약번호(응답에 포함된 경우), 결제기한이 포함됩니다.
- 옵션을 생략하면 일반실만 감시합니다. 특실도 함께 보려면 `--seat-class any`, 특실만 보려면 `--seat-class spe`를 사용하세요.
- 콘솔 상태는 `🟢` 좌석선택 가능, `🟡` 예약가능 표시는 있으나 선택 가능한 좌석조합 없음, `·` 매진, `?` 좌석검증 일시 실패를 뜻합니다.
- 같은 열차·좌석은 한 번만 알림하고, 다시 매진됐다가 재오픈되면 다시 알립니다.

## 주의

- 조회 주기를 너무 짧게(30초 미만) 두지 마세요. 계정/IP 이용 제한 위험이 있습니다.
- 처음에는 반드시 `--dry-run-reserve --once --no-telegram`으로 선택 결과를 확인한 뒤 `--reserve`를 사용하세요.
- 공석을 잡는 순간과 응답이 돌아오는 순간 사이에 좌석이 사라질 수 있습니다. 이 경우 다음 주기에 다시 시도합니다. 통신이 끊겨 예약 성공 여부가 불명확하면 중복 예약 방지를 위해 프로세스를 중단합니다.
- 예약 완료 후 정해진 시간 안에 결제하지 않으면 예약이 자동 취소될 수 있습니다. 텔레그램 알림을 확인해 직접 결제하세요.
- PC가 절전/최대절전에 들어가면 감시가 멈춥니다.
- 개인적인 좌석 확인 용도로만 사용하세요.
